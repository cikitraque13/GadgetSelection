OBJETIVO

Fijar la regla de claridad y decision comercial del sistema actual.

El sistema no existe para acumular productos.
Existe para ayudar al usuario a pasar de una necesidad real a una seleccion clara y a una decision de compra.

MANDATO

Cada pagina debe reducir ruido.

Cada necesidad debe responder a una intencion concreta.

Cada gadget debe aportar una funcion diferencial.

Si una tarjeta mete productos repetidos, confunde.
Si una card tiene demasiado texto, frena.
Si una necesidad mezcla mundos, contamina el catalogo.

FLUJO COMERCIAL

    problema
    -> gadgets
    -> decision
    -> Amazon

CRITERIOS DE CLARIDAD

Una seleccion valida debe cumplir:

    productos reales
    imagen correcta
    titulo limpio
    precio visible
    enlace Amazon
    ranking comprensible
    resumen corto
    mejor para claro
    no es para claro

CRITERIOS DE EXCLUSION

No meter productos solo para llegar a 8.
No duplicar gadgets sin funcion diferencial.
No mezclar necesidades.
No mezclar mundos.
No cambiar la necesidad para justificar un producto.

REGLA DE FRONTERA

La necesidad define el producto.
El producto no redefine la necesidad.

Ejemplos:

    localizadores-bluetooth no es seguridad-equipaje
    adaptadores-viaje no es energia-viaje
    outdoor-supervivencia no es energia-autonomia
    recuperacion pasiva de dolor no es entrenamiento-recuperacion
    frio-calor-recuperacion no es rodillos-foam

REGLA DE CARD

La card debe ayudar a decidir rapido.

Debe mostrar:

    imagen
    ranking
    ranking label
    nombre
    precio
    score
    summary
    mejor para
    boton Ver en Amazon

No debe mostrar:

    textos largos
    bloques editoriales
    ficha tecnica completa
    pros y cons largos
    mapas de solucion
    ranking intro gigante

REGLA DE CORRECCION

Si falla una imagen, se corrige la imagen.
Si falla un nombre de imagen, se renombra.
Si falla un JSON, se corrige el JSON minimo.
Si falla un precio, se corrige el dato.
Si falla un texto visual, se audita la fuente antes de tocar plantillas.

CIERRE

La claridad vende mas que la acumulacion.
Un catalogo bueno no es el que tiene mas productos.
Es el que ayuda a decidir sin perder confianza.
